How CKB DAO Watchdog Works

⚖️ How Voting Weights Are Calculated

CKB DAO governance uses Nervos DAO locked CKB capacity to determine vote weight. The Watchdog tool independently checks every single vote:

  • 1. Fetches voters: Gets all accounts who voted on the Metaforo poll and their recorded weights.
  • 2. Resolves addresses: Finds Neuron wallet addresses and converts any connected MetaMask Ethereum addresses to CKB PW-Lock addresses.
  • 3. Queries CKB Explorer: Finds all live cells with type nervos_dao_deposit for those addresses.
  • 4. Calculates total: Sums the capacity (in CKB) and compares it with what Metaforo recorded.
  • 5. Flags differences: If the on-chain sum doesn't match the recorded weight, it's flagged as Needs Review.

💻 Running from the Command Line

Prefer using a terminal? You can run the exact same logic with Python directly:

# 1. Activate your virtual environment
source .venv/bin/activate

# 2. Run the auditor script
python dao-v1.0/metaforo_watchdog_en.py <metaforo_url>

🐳 Running in Docker

# Run the Web UI
docker compose -f dao-v1.0/docker-compose.yaml up --build watchdog-web

# Or run the CLI version
docker compose -f dao-v1.0/docker-compose.yaml run --rm watchdog-web python dao-v1.0/metaforo_watchdog_en.py <metaforo_url>
